Core architectural principles currently established:

1. Raw harvest data is immutable.
2. Source claims must be preserved.
3. Canonical entities are derived interpretations, not raw truth.
4. Canonicalisation must be reversible.
5. Exploratory data analysis is a formal and necessary stage of workflow design.
6. GUI tools may inform work; scripts must reproduce work.
7. Legal conservatism overrides convenience.
8. AI assistance must be disclosed and procedurally constrained.
9. Deterministic scripting is preferred wherever feasible.
10. The system must support future migration and interoperability where practical.
11. Explicit provenance is more important than aggressive cleaning.
12. Deliverable architecture is more important than theoretically ideal architecture.
13. Harvest broadly; classify conservatively.
14. Acquisition, interpretation, and analysis must remain separable.
15. Canonicalisation decisions must preserve provenance and reversibility.
16. No authoritative data transformations should exist only inside GUI tools.

A critical early requirement is immutable PDF preservation.

For every downloaded PDF or source artefact, the system should preserve:
- source organisation
- landing page URL
- direct download URL
- retrieval timestamp
- local filename
- source filename if available
- checksum/hash (preferably SHA-256)
- file size
- HTTP metadata where available
- scraper/script version
- retrieval provenance

The project assumes:
- organisations may silently replace or revise PDFs
- provenance-sensitive preservation is therefore essential
- changed files must be treated as new artefacts, not overwritten updates

Key principle:
same URL + different hash = different artefact

Raw source artefacts should therefore be treated as immutable evidentiary objects.

All web collection must respect:
- applicable terms of use
- robots.txt where relevant
- rate limits
- copyright restrictions
- access boundaries

Do not design workflows that rely on:
- scraping authenticated sources
- bypassing access controls
- legally ambiguous collection practices

unless explicitly approved and documented.
