# 1. Project Purpose

The Australasian Educational Research project is building:

> a provenance-aware analytical infrastructure for examining the evidence base cited by selected Australian educational evidence organisations.

The current v0.1 focus is intentionally narrow.

Current in-scope organisations:
- CESE
- AERO

The primary intended early analytical use-case is:
- identifying the researchers, institutions, journals, and works influencing Australian educational evidence organisations.

---

# 2. Current v0.1 Objectives

The v0.1 system should support:

- reproducible acquisition
- immutable artefact preservation
- reference extraction
- preservation of source claims
- minimally viable provenance tracking
- reproducible analytical snapshots
- defensible exploratory analysis

The intended v0.1 success condition is NOT perfect infrastructure.

The intended v0.1 success condition is:

> a provenance-aware analytical substrate capable of supporting real research questions reproducibly.

---

# 3. Explicit Non-Goals

The v0.1 project is NOT:

- a universal scholarly graph
- a Google Scholar replacement
- a real-time indexing platform
- a SaaS platform
- a comprehensive Australasian corpus
- a production-scale research infrastructure
- a public search engine
- a full-text repository

Future expansion remains possible but is not assumed.
